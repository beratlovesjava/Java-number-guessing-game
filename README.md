# Number Guessing Game

A simple console-based number guessing game written in Java. The program generates a random number between 1 and 10, and the user has 3 attempts to guess it correctly.

## Overview

I built this project while learning core Java concepts—specifically working with loops, conditional logic, user input via `Scanner`, and random number generation. 

## Features

- Generates a random target number (1–10) for each session
- Tracks remaining attempts (3 tries per game)
- Input handling via standard console
